# Steven Orona Projects

Engineering portfolio: embedded systems, PCB design, power electronics, controls, and robotics.

Hosted with GitHub Pages. Everything lives in `index.html`; schematics and 3D models are in `assets/`.

## Updating
- Project text, tabs, and links are in the JSON block near the top of `index.html` (`<script id="state">`).
- Add a schematic as `assets/<project-id>-schematic.pdf` (or .png) and a 3D model as `assets/<project-id>-model.glb`, then point the project's `schematic` / `model` entries at them.
